# Application screenshots

`vendor-comparison.jpg` is a browser capture of the Infrastructure Impact web app,
taken on 25 October 2026 using the sanitized benchmark publication. It shows eight
vendors and eleven selected CVEs. Counts reflect that dated, bounded dataset;
they are not a security ranking or a statement of complete vendor coverage.

The capture includes the comparison interpretation notes and excludes browser
chrome, private research notes, raw vendor documents and account information.
