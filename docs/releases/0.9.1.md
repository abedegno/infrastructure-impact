# v0.9.1 research preview candidate

This candidate repairs product-scope expansion in the switching-study writer.
It replaces the published v0.9.0 source after its controlled activation timed out
and the runtime pin was rolled back. It is not an activation receipt.

Shared CSAF scores and remediations now retain each claim's exact explicitly
bound product ID after source/CVE/representation membership and preference
resolution. Source scopes are indexed once and repeated score candidate groups
are reconstructed once per extraction. Every claim remains present, including
unresolved families. Empty/unbound and reviewed HTML bindings, invalid/incomplete
diagnostics, scores, statuses, versions, conditions and remediation facts retain
their meanings.

Ordinary advisory metrics retain full valid publisher score scope and context;
original bytes and provenance preserve broader source facts. Narrowed claim JSON
does not reconstruct all publisher product-ID unions. The
[method clarification](../switching-comparison.md#schema-browser-adapter-and-native-api)
describes this existing-v1 subset representation. Corrected content can change
claim IDs and normalizer fingerprints. Advisory identities, advisory-v2, frozen
definitions and original review resources are unchanged.

Closed source-object uniqueness uses an indexed check with the same duplicate
rejection and strict item validation. Independent writer/new-input validation
remains in place. Flushed metadata-only phase timings cover collection, benchmark
coverage, reporting, query, projection, writing and backup without payload or
error serialization.

No workflow timeout, storage, delivery, monitor or archive budget is raised.
Dependency pins, lock revision, schedules, permissions, default sources and
recovery settings are unchanged. Example vendor plugin 0.1.8 already declares
compatibility with 0.9.1. Assets contain source and a wheel, never public vendor
captures, private vaults or operational recovery material.

See the [failed activation receipt](../rollouts/2026-11-05-switching-activation-failed.md)
and [replacement proposal](../rollouts/2026-11-05-switching-091-proposal.md).
Renewed exact-commit approval follows independent review, exact-head CI and
candidate asset verification. Single-source local performance replay does not
certify a complete hosted rollout, recovery availability or source coverage.
