# v0.9.0 research preview

This source release adds a descriptive campus/branch switching study for Cisco
IOS XE, HPE Aruba Networking AOS-CX and Arista EOS. Source releases and evidence
publications retain separate identities. Publishing this release does not
activate the hosted collector or certify complete vendor coverage.

## Included

- Independent OS-family/model-qualified, vendor and period selections, with
  generation-bound evidence tracing and JSON/CSV downloads.
- Opt-in bounded Cisco OpenVuln OAuth collection and resumable official
  Aruba/Arista history enumeration, with explicit errors and unknown totals.
- Vendor-reported CVSS, separate advisory ratings, official CVE/NVD fallback and
  full-study KEV membership; no independent CVSS recalculation.
- Explicit source-linked scope, conditions, bundles and remediation-publication
  events, without automatic version/model matching or inferred fix dates.
- Matching Python/browser evidence validation, compact monitoring and packaged
  resources. Owned immutable inputs and bounded detail rendering make repeated
  selections substantially cheaper than initial full-study loading.
- Example vendor plugin 0.1.8, declaring compatibility through the 0.9 series.

## Evidence limits

Counts measure disclosure, not vendor security quality; higher disclosure can
reflect more scrutiny. The [staged observations](../research/2026-11-04-switching-backfill-summary.md)
retain Cisco authentication gaps, missing Aruba pre-2022 enumeration, 53 unparsed
Arista documents, publisher drafts and insufficient explicit target-model
bindings. These historical observations are not a new hosted backfill.

Independent human review remains pending. No security ranking, equivalence,
concealment finding, actual upgrade-effort estimate or verified fix-delay
comparison follows from this release. Zero model-qualified observations do not
establish no exposure. Full study inputs are an explicit large download; initial
validation still takes seconds on the staged dataset.

## Compatibility and activation

Advisory schema v2, frozen research definitions, default sources and existing
identifier meanings remain unchanged. New study contracts and operational
migrations are additive. Unreleased study claim IDs use the documented common
numeric fingerprint representation; reported score values are unchanged.

The source tag does not publish to PyPI or a container registry. Release assets
contain reviewed source, a wheel and checksums, never vendor captures, local
vaults, credentials, operational receipts or recovery drafts. See the separate
[activation proposal](../rollouts/2026-11-04-switching-activation-proposal.md).
