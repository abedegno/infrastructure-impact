# v0.13.0 research preview candidate

Status: prepared for review. Source publication, the hosted full CI matrix,
runtime-pin activation, collection and live verification are pending. This
candidate does not claim that the public site has the new view or source set.

Customer switching comparison combines the existing selected Cisco IOS XE,
Aruba AOS-CX and Arista EOS study with provider severity, KEV, literal fixed
versions and separate release/bundle/support context. The compact overview uses
the selected study facts in fixed vendor order; detailed evidence remains below.
Native `/api/v1/customer-comparison`, static v1/v2 delivery and browser
`#customer-comparison` share generation-bound JSON/CSV and explicit missing-history
behavior. See the [method and interfaces](../switching-comparison.md).

Reviewed Aruba links retain the affected product section and release association.
Arista fixed-only statements retain product/CVE ownership without creating
affectedness. Dates from release tables, advisory availability, notice publication
and bundle member publication remain separate. Models, installed versions,
upgrade paths, actual customer upgrades and complete historical denominators
remain unknown. Publication counts do not rank vendor security.

The packaged `resources/sources.json` adds four enabled reviewed public reference
entries: Aruba 10.14 history, 10.16 history, 10.14 supported products, and Arista
advisory 0148. Cisco IOS XE Dublin 17.12.1 is present but explicitly disabled
after blocked anonymous acquisition. Existing reference collection owns retrieval;
there are no new schedules, credentials or permissions. Operators must verify the
effective hosted source configuration before activation: packaged defaults do not
rewrite an existing operator file.

Package/lock and Compose labels are 0.13.0. Example plugin 0.1.12 extends its
compatibility bound through the 0.13 series. Dependency versions are unchanged.
The [bounded cached public replay](../research/2026-11-09-customer-comparison-replay.md)
is integration evidence, not a production dataset or fair vendor comparison.
