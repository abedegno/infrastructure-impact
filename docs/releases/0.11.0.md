# v0.11.0 research preview candidate

Status: prepared for review; no source tag, release publication or hosted activation
is claimed. This candidate packages PRs #28–30 and dependency PRs #9, #10 and #12.

## Changes

- Add local `impact cve-reconcile` commands for verified, pinned official CVE List
  snapshots, bounded resumable discovery, explicit immutable collection baselines
  and provenance-bound JSON/CSV reports. This is an opt-in local workflow, not a
  hosted feed, automatic advisory ingestion or an expansion of the website cohort.
- Correct the exact reviewed Arista SA-0099 CVE/version grouping. Select reviewed
  SA-0103 HTML from either reviewed entry URL, retaining the contradictory
  advertised CSAF as alternate evidence with a visible issue. Do not transfer its
  CVE identity or versions into the HTML advisory.
- Reduce repeated switching comparison schema traversals and copying while
  retaining fresh public validation, semantic checks, exact returned-input checks
  and independent publication snapshots. Full-size validation remains expensive.
- Update Ruff to 0.17.3, pytest to 9.2.0 and the reader container to Python 3.15.
  The hosted collector workflow still selects Python 3.13. Update example plugin
  0.1.10 to declare compatibility through the 0.11 series, subject to the installed
  wheel and external-plugin acceptance gate.

## Evidence and limits

The [repair observations](../research/2026-11-06-arista-comparison-repair-observations.md)
record original-source Arista replay and all 18 JSON/CSV comparison export pairs
over 91,396 staged study claims. This bounded public-only local stage is separate
from the hosted collection. Its model-qualified rows have no supported
observations for the requested Cisco, Aruba and Arista hardware; that is missing
evidence, not unaffectedness or a fair exact-platform comparison.

The [reconciliation guide](../CVE_RECONCILIATION.md) describes unsupported formats,
size bounds, ambiguous leads and unknown historical completeness. Neither scan
completion nor a recovered vendor reference establishes complete vendor history.
Human impact review remains pending. Disclosure counts cannot establish vendor
security quality, equal exposure, patching burden or intentional concealment.

Advisory schema v2, frozen studies, source defaults, schedules, hosted permissions,
recovery settings and application/storage budgets remain unchanged. The shared
switching adapter contributes to every built-in normalizer fingerprint, so this
release changes those identities across vendors. Fingerprint changes alone do
not establish semantic changes and do not authorize broad normalization replay.

Older normalized revisions remain retained. An ordinary collection is not a
historical cleanup: old contradictory Arista records may remain visible, and
unsupported retained representations fail visibly rather than being renamed or
silently deleted. Local fixes and research acceptance do not promise immediate
website count changes.
