# CISA KEV Enrichment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. This preserves the maintainer's selected execution method. Steps use checkbox (`- [ ]`) syntax for tracking. Implementation starts after maintainer review of this plan.

**Goal:** Add generation-bound CISA KEV intelligence, filtering and exports without changing vendor affectedness or research evidence contracts.

**Architecture:** Retain the official CISA mirror through the reference-source pipeline, partition enrichment from study inputs, and publish a compact strict report. Pure Python and JavaScript selectors share fixtures and freshness rules; native HTTP and the static adapter use those selectors. Readers never retrieve a newer feed to supplement an existing publication.

**Tech Stack:** Existing Python >=3.11, SQLite, jsonschema, vanilla JavaScript, pytest and Node tests; stdlib operational monitor. No new runtime dependency or SQL migration.

**Spec:** [Approved design](../specs/2026-11-02-cisa-kev-design.md).

## Global Constraints

- Feed URL: `https://raw.githubusercontent.com/cisagov/kev-data/develop/known_exploited_vulnerabilities.json`; canonical attribution: `https://www.cisa.gov/known-exploited-vulnerabilities-catalog`. No automatic transport fallback.
- Bound raw feed at 8,000,000 bytes and catalogue at 20,000 entries; require nonempty complete validated content.
- Effective states: `listed`, `not_listed`, `unknown`. Verification older than 36 hours, latest failed attempt, missing verification, disabled/unconfigured source, or check more than five minutes in the future yields unknown.
- Preserve 512,000-byte target, 8,000,000-byte maximum part, 2,000,000-byte index and 20,000,000-byte default-monitor budgets.
- Full sorted membership index; detailed entries only for imported/benchmark CVE union. Exact CVE joins only. No vendor/product-name inference.
- Publication identity/time are immutable; selected views record separate `evaluated_at`. No vendor assessments, inventory assertions, frozen-study changes, new enrollment or single-dossier schema changes.
- Public root/bundled source configs change together. Preserve the existing native custom `sources.json`, native evidence, frozen human review files, observation anchors, schedules, recovery controls and runtime pin.
- Only synthetic test fixtures. Public artifacts exclude raw captures, private data and ignored operational reports. Source release/activation follows review; do not dispatch a hosted collection while implementing this plan.

## Review Focus

1. HTTP 304 or cached invalid bytes after a failed parse must not fabricate a verified success (Task 1).
2. A missing/disabled custom source with retained historical entries must not become fresh merely because another source collected successfully (Tasks 1–2).
3. Boundary clocks, timezone offsets and a page left open past 36 hours must agree across Python and JavaScript (Tasks 2, 4).
4. Empty effective cohorts, repeated/blank query parameters and vendor selection must behave identically through the real native/static request paths (Task 3).
5. A slow successful request after a newer failed or successful filter request must not replace the committed evidence or its downloads (Task 4).

## File and Interface Map

- `references/kev.py`: bounded publisher parser; `references/registry.py`, `storage.py`: purpose partition and retained/check metadata.
- `application/kev.py`, `schemas/kev-v1.json`: report construction, validation and pure selection. Keep separate from `research_reports.REPORTS`.
- `web/kev.js`: pure browser evaluation/selection and safe attributed presentation helpers; loaded before snapshot/app scripts.
- `application/query.py`, `publication.py`: internal enrichment input, public projection, publication binding and assets.
- `exports.py`, `http.py`, `web/snapshot.js`: selection, query parsing and export parity.
- `web/index.html`, `app.js`, `style.css`: existing-view integration and atomic state/download commitment.
- `checks/public_health.py`, distribution/release tests, OpenAPI and documentation: standalone verification, packaged resources and operating instructions.

All paths above are relative to `infrastructure_impact/` except `checks/`. Tests listed below define new names where no suitable existing test exists. Reuse existing fixtures/helpers rather than duplicate an application harness.

## Task 2: Strict Report and Shared Freshness Semantics

**Files:** Create `infrastructure_impact/application/kev.py`, `infrastructure_impact/schemas/kev-v1.json`, `infrastructure_impact/web/kev.js`, `tests/test_kev.py`, `tests/test_kev.js`, `tests/fixtures/kev-selection-cases.json`.

**Interfaces:**

- `build_report(source_input: dict, scope: list[str], *, publication: dict | None, generated_at: str) -> dict` builds a strict v1 report, initially evaluated at generation time. Publication is null only for unpublished query output or missing legacy context; published report validation requires its enclosing publication identity. `validate_report(report: dict) -> None` uses the packaged schema with format checking; reject unknown structural properties.
- Report top-level keys: `schema_version`, `publication`, `generated_at`, `evaluated_at`, `source`, `catalogue`, `policy`, `listed_cve_ids`, `entries`, `selection`. Source keys: `id`, `retrieval_url`, `catalogue_url`, `configured`, `enabled`, `availability`, `latest_attempt`, `checked_at`. Availability values: `available`, `not_configured`, `disabled`, `missing`, `failed`, `stale`, `future`. Latest attempt is null or `{checked_at, outcome, error_code}`. Catalogue is null or `{version, released_at, count, sha256, revision_id, source_observed_at, parsed_at, parser_version}`. Revision ID is a string. Preserve literal source times.
- Policy keys: `max_bytes=8000000`, `max_entries=20000`, `fresh_for_seconds=129600`, `future_tolerance_seconds=300`. `listed_cve_ids` always contains the retained complete sorted unique index, even when historical; `entries` contains only scope-intersecting retained records. No raw payload/storage path is public.
- `select_report(report: dict | None, requested: list[str], *, kev_only: bool = False, evaluated_at: str | None = None) -> dict`; absence yields explicit missing-source report. Selection keys: `requested_cve_ids`, `effective_cve_ids`, `kev_only`, `membership` (requested ID to effective status). Unfiltered effective scope equals requested scope; filtered scope intersects fresh index. Missing detailed metadata never blocks membership lookup. Throw `KevUnavailable(ValueError)` with `code="kev_unavailable"` when a filtered selection cannot be evaluated reliably.
- `window.InfrastructureKev.selectReport(report, requested, {kevOnly=false, evaluatedAt=null}={})` mirrors Python, throwing an error with the same code. `module.exports` also exposes this function for Node tests. All report transforms copy inputs; default evaluation time is current UTC, injectable in both languages.
