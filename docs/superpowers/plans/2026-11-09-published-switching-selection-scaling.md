## Selected design after diagnosis

Publish one optional generic `switching-row-sources.json` root with a closed v1 schema. Each native default vendor row binds its original snapshot row hash, exact claim/event membership digest and increasing ordinals into the existing canonical global Sources array. It duplicates no Sources, changes no catalog/envelope fields, stays out of runtime/snapshot archives and is bounded to 8 MB. A present malformed index rejects; old artifacts retain their existing fallback.

Both readers derive actual summaries from authenticated whole published rows and exact selected Source ranges for the same default scope/window and null CVE selection. Nondefault scope/window and non-null CVE selections retain complete reduction. Generation, definition, row/range ownership, numeric kinds, budgets, cancellation, detail cursors and canonical JSON/CSV remain checked. The publisher and independent native verifier derive membership from complete validated evidence; certification additionally compares each vendor's summary/CSV against native facts, without another full-report proof round solely for those three checks.
