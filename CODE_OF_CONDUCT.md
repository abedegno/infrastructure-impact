# Community conduct

Be respectful, specific and constructive. Critique evidence and code, not people.
Welcome contributors with different backgrounds and experience. Give credit for
others' work, respect privacy and correct mistakes when evidence changes.

Harassment, threats, discriminatory abuse, doxxing, spam and deliberate disclosure
of confidential material are not acceptable. Do not use this project to make
unsupported accusations about researchers, vendors or individuals.

These expectations apply to project issues, pull requests, discussions and other
spaces maintained by this project. Maintainers may edit or remove material, close
threads or restrict participation to protect the community. Decisions should be
proportionate and explain the relevant behavior where privacy permits.

For a conduct concern, request private maintainer contact without posting personal
or sensitive details. If GitHub moderation/reporting is appropriate, use the
platform's reporting tools. Maintainers must recuse themselves from handling a
report about their own conduct.
